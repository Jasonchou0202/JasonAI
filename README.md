# 章鱼哥 AI 工作室 · 生意手账

手机和电脑共用的私人销售账本。三个常用入口：看板、记一笔、销售明细。

前端发布地址：[打开生意手账](https://jasonchou0202.github.io/JasonAI/)。未配置 CloudBase 时，页面只提供明确标记的虚构演示；真实云端保存需要完成 [部署步骤](docs/deployment.md)。

## 日常使用

- **记一笔**：选常用商品自动带出售价和成本，填写客户，核对日期和利润，保存。金额可改。连续录入使用“保存并继续”，保留日期和商品，清空客户。
- **看板**：查看今日、本周、本月和累计利润。切换日、周、月走势，点击数字或柱形进入对应明细。
- **明细**：按客户、商品、日期查账，可编辑；删除后进入回收站，可恢复。筛选后的全部记录可导出 CSV。
- **设置**：维护商品，导入飞书销售表，下载 JSON 完整备份。恢复仅用于空账本。
- **网络失败**：显示“未保存”，内容留在本机草稿中，联网后用同一草稿重试。看到“已保存”才表示后台已确认。手机和电脑的本机草稿互不共享。

利润 = 销售额 − 成本（出资）。金额以整数分存储；日期按北京时间，周一到周日是一周，自然月统计。零收入和负利润正常保留。

## 本地运行

Node.js 22.12+（或 24+）：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/JasonAI/`。未配置账号时点击“先看看演示账本”。

```sh
npm run check
```

执行业务测试、TypeScript 检查、前端构建和云函数打包。输出 `dist/` 和 `cloudfunctions/sales/index.js`。

## 历史迁移

从飞书导出完整销售表，核对导出时的总记录数、销售额、出资、纯利和逐月纯利。支持 CSV/XLSX/XLS 的第一张工作表，自动匹配商品名称、客户名称、日期、销售额、出资（或成本）、纯利（或利润）、备注。

导入先预检，空金额、日期错误、原利润差异会显示行号并阻止确认。同一文件按 SHA-256 识别，重试不会重复添加；不同文件的相似订单会提示，确认后保留，避免误删真实同额订单。表格每次最多 2000 行、10 MB。备份文件最多 20 MB；实际云函数请求体上限以环境为准，超限时不恢复。

详见 [迁移和上线核对表](docs/acceptance.md)。真实销售资料只放本地忽略的 `private-data/` 或自己的云端账本。

## 实现

React + TypeScript + Vite，Hash 路由和 `/JasonAI/` 路径。CloudBase 云函数通过可信身份上下文核验固定 `OWNER_UID`，数据库客户端权限关闭；未绑定所有者时拒绝全部业务访问。导入与恢复分批提交事务，未完成的销售批次不进入统计。统计读取全部数据页，明细每页 30 条。

SDK 间接依赖通过 overrides 更新 Axios，并将旧 lodash.set/unset 接口转接至已修复的完整 lodash。`package-lock.json` 固定依赖。仓库与构建产物不放密码、Secret Key、真实销售或客户文件。
