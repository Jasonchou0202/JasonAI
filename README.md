# 章鱼哥 AI 工作室 · 生意手账

手机和电脑共用的私人销售账本。四个常用入口：看板、记一笔、销售明细、客户日程。

前端发布地址：[打开生意手账](https://jasonchou0202.github.io/JasonAI/)。未配置 CloudBase 时，页面只提供明确标记的虚构演示；真实云端保存需要完成 [部署步骤](docs/deployment.md)。

## 日常使用

- **记一笔**：选常用商品自动带出售价和成本，填写客户，核对日期和利润，保存。金额可改。连续录入使用“保存并继续”，保留日期和商品，清空客户。
- **看板**：查看今日、本周、本月和累计利润。切换日、周、月走势，点击数字或柱形进入对应明细。
- **核心客户**：默认全部时间累计利润前 20 名，可切换月、自然季、半年和年度，展开全部并搜索客户、别名或商品；点击客户进入销售和日历。月周期显示所选月，其余周期进入全历史详情。
- **日程**：选择客户和北京时间，记录事项、反馈和下一步计划。支持完成、重新打开、改期、删除与恢复；点击“安排下一次”带出计划。绿色为完成，橙色为今明尚未到期，红色为逾期或其他待办；日历保留同一天的混合状态。
- **客户别名**：名称中的 ✅ 和末尾 IPv4 自动隐藏，新录入的同名变体归属到已有客户。设置里的“疑似同一客户”展示销售、利润及日程预览，可一键合并或确认全部合并，支持解除；大小写差异需要确认，历史销售原文保持不变。
- **明细**：按客户、商品、日期查账，可编辑；删除后进入回收站，可恢复。回收站支持二次确认彻底删除，此操作不可恢复。筛选后的全部记录可导出 CSV。
- **设置**：维护商品，导入飞书销售表，下载 JSON 完整备份。恢复仅用于空账本。
- **网络失败**：显示“未保存”，内容留在本机草稿中，联网后用同一草稿重试。看到“已保存”才表示后台已确认。手机和电脑的本机草稿互不共享。

利润 = 销售额 − 成本（出资）。金额以整数分存储；日期按北京时间，周一到周日是一周，自然月统计。零收入和负利润正常保留。

## 本地运行

Node.js 22.12+（或 24+）：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/JasonAI/`。未配置账号时点击“先看看演示账本”。

```sh
npm run check
```

执行业务测试、TypeScript 检查、前端构建和云函数打包。输出 `dist/`、`cloudfunctions/sales/index.js` 和 `cloudfunctions/reminders/index.js`。

浏览器流程测试：`npx playwright install chromium`，然后 `npm run test:e2e`。使用固定时钟和虚构账本验收周期排行、合并、日程、手机布局及离线草稿；GitHub Actions 中测试通过后才发布 Pages。

本地后台部署：参照 `docs/deploy-env.example.json` 创建被 Git 忽略的 `private-data/deploy-env.json`，填写现有身份和提醒配置；先执行 `tcb login`，再 `npm run deploy:functions`。脚本只部署现有环境中的两套函数与分钟触发器，不购买服务、不输出密钥。未登录则输出控制台步骤。CLI 配置说明见 [官方文档](https://docs.cloudbase.net/cli-v1/functions/deploy)。

网页外壳和静态资源支持离线缓存；登录、云接口和真实业务数据不会进入缓存。断网时仍可填写本机草稿，联网并成功登录后才能读取云端账本或保存。

## iPhone 提醒与备份

在 iOS 16.4 或更新版本，用 Safari 打开网站，通过分享菜单添加到主屏幕。再从主屏幕打开、登录，在设置中开启此设备提醒并发送测试通知。默认提前 15 分钟和到点各提醒一次；网页关闭后由独立后台触发，不补发创建前已错过的时点。系统网络、专注模式和通知权限会影响实际送达；“已提交”需要在手机上确认收到。部署方法见 [提醒后台说明](docs/reminders.md)。

完整 JSON 备份为版本 2，包含客户关联和日程，仍兼容版本 1。恢复仅用于空账本，保留完成状态和原有归属，不重放历史提醒；恢复后设备需重新开启推送。推送订阅和服务端私钥不包含在业务备份中。

## 历史迁移

从飞书导出完整销售表，核对导出时的总记录数、销售额、出资、纯利和逐月纯利。支持 CSV/XLSX/XLS 的第一张工作表，自动匹配商品名称、客户名称、日期、销售额、出资（或成本）、纯利（或利润）、备注。

导入先预检，空金额、日期错误、原利润差异会显示行号并阻止确认。同一文件按 SHA-256 识别，重试不会重复添加；不同文件的相似订单会提示，确认后保留，避免误删真实同额订单。表格每次最多 2000 行、10 MB。备份文件最多 20 MB；实际云函数请求体上限以环境为准，超限时不恢复。

详见 [迁移和上线核对表](docs/acceptance.md)。真实销售资料只放本地忽略的 `private-data/` 或自己的云端账本。

## 实现

React + TypeScript + Vite，Hash 路由和 `/JasonAI/` 路径。CloudBase 云函数通过可信身份上下文核验固定 `OWNER_UID`，数据库客户端权限关闭；未绑定所有者时拒绝全部业务访问。导入与恢复分批提交事务，未完成的销售批次不进入统计。统计读取全部数据页，明细每页 30 条。

SDK 间接依赖通过 overrides 更新 Axios，并将旧 lodash.set/unset 接口转接至已修复的完整 lodash。`package-lock.json` 固定依赖。仓库与构建产物不放密码、Secret Key、真实销售或客户文件。
