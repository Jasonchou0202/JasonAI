## 真机走查（第 3 批）

每条写清楚操作和预期结果，做完在方框里打勾。

### 10a 导入 Excel（管理员）
- [ ] 打开「设置与更多 → 导入飞书历史 Excel」，从文件传输助手里选一个 .xlsx。预检数字（条数、销售额、纯利、按月）和网页预检**完全一致**。
- [ ] 表格缺列时，显示「缺少必需列：…」，导入按钮是灰的。
- [ ] 点确认导入，进度条走完，提示「已导入 N 条」；网页刷新以后能看到这些记录。
- [ ] 同一个文件再导一次，提示「此文件已经导入，未重复添加」（网页和小程序导同一个文件，也算同一批）。
- [ ] 用成员身份打开这个页面，会退回「设置与更多」，而且看不到「账本」这一组。

### 10b 备份与恢复（管理员）
- [ ] 点「生成备份并发到聊天」，发给文件传输助手。电脑上打开的 JSON 和网页下载的备份格式一样：`format` 是 `zhangyuge-sales`，`version` 是 2。
- [ ] 发完以后，手机的小程序目录里不留这个文件（开发者工具 → 存储 → 文件里看不到）。
- [ ] 往有数据的账本恢复，提示「备份恢复仅用于空账本，现有记录不会被覆盖」，账本里的数据不变。
- [ ] 往空的测试环境恢复（**不在正式账本上做**），进度走完，条数对得上。
- [ ] 账本太大时，提示「请在网页上下载」，不会报错白屏。

### 10c / 15 微信服务通知
- [ ] `MINIAPP_NOTIFY_ENABLED` 关着时，页面显示「暂未开放」，点不了订阅。
- [ ] 开关打开、模板 ID 配好以后，点「再订阅一次」，弹出微信订阅框；选「允许」后，次数加 1。
- [ ] 建一条 15 分钟后的日程（提醒选「提前和到点」），到点前 15 分钟和到点各收到一条服务通知；点通知能进入小程序。
- [ ] 次数用完以后，不再收到通知；网页推送和 iPhone 同步照常。
- [ ] 有人提交申请时，管理员收到一条「新申请」通知。通知里**没有**手机号。
- [ ] 实测定时器里能不能用云调用发消息（方案附录 D 留的唯一一项）。不能用的话，记下错误码，改走备用方案，备用方案要另外说「上」。

### 11a 头像
- [ ] 拍照或从相册选图，裁成正方形，预览是圆的；点「用这张」，网页的成员列表里也换成新头像。
- [ ] 「换回默认头像」以后，两边都显示名字首字。
- [ ] 成员只能改自己的头像。
- [ ] 头像开关关着时，页面显示「还没打开」。

### 13 / 13a 内容生产（管理员）
- [ ] 今日获客：四个来源合计不等于新增好友时，提示对不上，保存不了。
- [ ] 保存以后，网页「内容生产」里同一天的数字一样；在网页改完，小程序下拉刷新能看到新的版本号。
- [ ] 内容看板只读版：数据时间、本周数字、七段流水线、选题进度、等拍板、风险都有。「复制网页链接」能复制。
- [ ] 成员看不到内容生产入口；直接打开页面路径会被退回。

### 16 示例数据
- [ ] 「看示例数据」选管理员视角进入：首页、明细、日程显示的都是「示例客户 · …」，不是真实客户。
- [ ] 示例里记一笔、删一笔，退出示例以后，真实账本一条都没变（网页核对）。
- [ ] 选成员视角时，回收站、成员管理这些只给管理员的功能都进不去。
- [ ] 没批准的微信，看不到示例入口。
